# Sécurité et confidentialité

Bouclier sert à protéger des données personnelles : un oubli de masquage ou de nettoyage est un problème sérieux.

## Signaler un problème

Ouvrez un [ticket](https://github.com/rudysooo/bouclier/issues/new/choose) en décrivant :

- la version de Bouclier (page « Paramètres ») ;
- ce que vous avez fait ;
- ce qui aurait dû être masqué ou retiré.

**Les tickets sont publics.** N'y mettez jamais un vrai document ni de vraies données personnelles : reproduisez le problème avec des données inventées.

## Versions suivies

Seule la dernière version publiée reçoit des corrections.
